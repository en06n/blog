# HTTPメソッドを理解する
主要なメソッドを理解するために、ローカルサーバーをRustで立てました。（[詳細はGithubにあります](https://github.com/en06n/mini-http-server)）
````Rust
use std::net::TcpListener;

fn main() {
    let listener = TcpListener::bind("127.0.0.1:8080").expect("Failed to bind");

    println!("Server is running at http://127.0.0.1:8080");

    for stream in listener.incoming() {
        match stream {
            Ok(_) => {
                println!("Client connected!");
            }
            Err(e) => {
                eprintln!("Connection failed: {}", e);
            }
        }
    }
}
````

# ハイパーメディアフォーマット
## HTML

の2種類があるが、html -> 人間向け、xml-> データ処理用という認識。

## XML
主な特徴としては「XML文書は木構造として表現できる」ことが挙げられる。
### 属性
要素は属性を持てる。例えば、リンク先のURLを指定する属性（href 属性）は以下のように書ける。
href="https://example.com"を1つの組とする。開始タグは複数の属性を持つことができる。
```html
<a href="https://example.com">Example</a>
```
a：要素名
href：属性名
https://example.com：属性値
Example：要素内容

## 名前空間
複数のXMLフォーマットを組み合わせるときに、名前の衝突を防ぐ目的で使われる。
```xml
<document
    xmlns:user="http://example.com/user"
    xmlns:item="http://example.com/item">
    <user:name>Alice</user:name>
    <item:name>Apple</item:name>
</document>
```
例えば、nameという属性が複数存在する場合、
1. 名前空間宣言をする
```xml
xmlns:user="http://example.com/user"
xmlns:item="http://example.com/item"
```
2. 接頭辞:属性のように書く
http://example.com/user のname -> user:name
http://example.com/item のname -> item:name

というように接頭辞をつけることで、衝突を回避できる。


## HTMLの構成要素
主にヘッダとボディが構成要素となっている。
### ヘッダ(head)
メタデータとして**title・link・script・meta**などが要素としてある。
### ボディ(body)
- ブロックレベル要素：**h1・div**といったよくみる文書のかたまりを表現するための要素
- インライン要素：ブロックレベル要素に入る要素。**em・strong・a**といった強調や改行、画像埋め込みなどを表現する。
### 共通の属性
HTMLのすべての要素は**id属性・class属性**を持てる。
